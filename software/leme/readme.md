# leme

![leme](https://github.com/flavioamiero/leme-macropad/raw/main/assets/leme-macropad.png)

A simple macropad with six keys, a rotary encoder and a small screen

* Keyboard Maintainer: [Flávio Amieiro](https://github.com/flavioamieiro)
* Hardware Supported: Custom PCB released as open hardware
* Hardware Availability: https://github.com/flavioamieiro/leme-macropad

Make example for this keyboard (after setting up your build environment):

    make leme:default

Flashing example for this keyboard:

    make leme:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

To enter the bootloader , hold down the top left key while you plug in the macropad.
